## 批次 3：归属、游戏和影视详情

### 资源库归属

每次扫描固定一份配置快照，以包含路径的最具体资源库根目录决定新扫描的归属；相同根目录使用资源库 ID 确定稳定顺序。父库跳过已配置的嵌套库，书籍、Calibre 导入、游戏及视频遵循同一边界。已登记为其它库的文件继续保留原记录，扫描不偷偷迁移其 ID 或私人状态。

`GET /api/libraries/{id}/ownership-preview` 只读返回嵌套排除根目录、旧记录冲突数量和最多 12 条示例，管理界面可查看。**本批未执行线上旧归属重分配、合库或去重**；旧冲突需要依据预览另行制定和核验迁移方案。

### 游戏多盘与依赖

客户端游戏投影新增可选 `discGroupInfo`。只识别支持的光盘平台中明确的 Disc / Disk / CD 数字标记；原文件名中的地区、修订、语言、pilot、demo 等版别信息保留。资源库、目录、平台和格式共同限制分组，内容哈希不用于合并。

网页游戏库将已加载且盘号不重复的条目折叠为可展开组；盘数标明“已加载”。每张盘仍使用原游戏 ID、收藏、喜欢和合集操作。单张盘、重复盘号保持独立。**这是显示分组，不创建虚拟播放列表，不改启动清单，不合并或删除数据库记录、ROM 或存档**；已有 PC-98 源聚合和 PC-FX 虚拟 M3U 逻辑保留。

现有 MAME 审计工具增加依据 `isbios`、`isdevice` 及非可运行对象的 `romof` / `device_ref` 关系分类依赖，并在分类前验证对应 ROM 内容。可运行父集和克隆仍独立保留，`cloneof` 本身不构成隐藏依据，内容不匹配继续等待整理。分类遍历包含依赖，防止角色变化导致分页漏项；旧启动配置不能将依赖重新提升为游戏。**本批未在运行服务执行全库目录重建**；未知旧记录不会仅因部署而获得新的目录认证。

### 影视详情

作品版本/剧集列表补充已有文件规格：格式、大小、时长、分辨率和音视频编码；播放进度按当前档案读取。作品详情可显示原名、片长、类型、导演/主创、演员及带人数的 TMDB 评分。

在线资料是可选操作：只有已匹配 TMDB 的作品且服务器已启用提供方时才提供获取入口；普通详情读取只读现有缓存。按需请求复用现有配置和限流通道，24 小时内复用新鲜详情，处理提供方退避，响应大小有上限。写入仅更新提供方缓存中的 `details`，校验作品/提供方身份与缓存有效期；过期、清除或重匹配后的旧响应不能覆盖新身份。手动元数据、文件关联与播放状态保留。本地测试使用模拟响应，没有据此声称已完成真实 TMDB 请求验收。
