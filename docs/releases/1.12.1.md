# FolioSpace Library 1.12.1

The web EPUB reader now uses the available fullscreen reading area in
single-page and spread layouts, including on wide displays. Exiting fullscreen
restores the windowed layout.

This update requires no database migration and works with standalone MCP 1.04.

## Upgrade

The Docker image supports Linux AMD64 and ARM64.

```sh
docker pull funland/foliospace-library:1.12.1
```

Keep your persistent configuration, access token, and media mounts when
updating. See the
[Compose quick start](https://github.com/funland/foliospace-Library/blob/v1.12.1/COMPOSE-QUICKSTART.md).
