# FolioSpace Library 1.12

The web comic reader now scales single pages and spreads to fit the fullscreen
reading area. Pages keep their original proportions and stay fully visible.
Spreads sit side by side on wide screens and stack on narrow screens. A lone
final page uses the full reading area. Exiting fullscreen restores the windowed
layout.

The release includes the existing Library 1.11 features and works with
standalone MCP 1.04. This update introduces no database migration.

## Upgrade

The official image supports Linux AMD64 and ARM64:

```sh
docker pull funland/foliospace-library:1.12
```

Keep your persistent configuration, access token, and media mounts when
updating. If you maintain local patches inside your container, carry those
patches forward before replacing it. See the
[Compose quick start](https://github.com/funland/foliospace-Library/blob/v1.12/COMPOSE-QUICKSTART.md).
