# FolioSpace Library 1.10

This release improves library organization and EPUB reading, and makes rescans
and file diagnostics preserve existing identities and user state.

## Library browsing and metadata

- Ebook/comic type switching and EPUB/PDF filters make ordinary ebooks easier to find in mixed libraries.
- Calibre metadata supplies titles, authors and covers instead of directory-name fallbacks. Generated comic labels and collection subtitles are cleaned, and nested directories are grouped more clearly.
- Library administration moves into settings. Video titles are consistent across home surfaces, release-name noise and generated `sample` labels are cleaned, and filenames can supply missing years.
- Finished books leave Continue Reading; localization and action labels are more consistent.

## EPUB reading

- Restore left/right arrow-key navigation, including focused EPUB content.
- Improve two-column sizing and preserve reading location through layout changes and restore events.
- Correct chapter labels, inline character images and footnote navigation.

## Data preservation and diagnostics

- Rescans and collection-ownership reconciliation preserve book IDs, progress, favorites and manual metadata. Ownership migration remains an explicit preview/apply operation; upgrading alone does not run a whole-library migration.
- Mixed libraries no longer accidentally invoke the legacy game analyzer. Normal game analysis and helper rebuilds preserve manual curation.
- Confirmed empty, zero-filled or structurally invalid book files receive explicit labels and are excluded from Recently Added. Existing records, source files, error reasons and original paths are retained.
- Successful validation of a repaired supported file clears its active diagnostic while retaining historical errors. The authenticated `POST /api/books/{id}/validate` endpoint updates diagnostics only.
- Structural validation covers EPUB package/spine, PDF headers and ZIP/CBZ directories. It does not decode every page or fully parse PDFs. Nonempty 7z files receive only limited zero-content checks; path/access failures are not classified as confirmed corruption.

Existing video-library, Range delivery, game launch and reader hotfixes remain
included. The separately released MCP 1.03.1 tools and episode-availability fix
are retained; this server release does not change the MCP package version.

## Upgrade

```sh
docker pull funland/foliospace-library:1.10
```

The Docker release targets **Linux AMD64 and ARM64**, with tags `1.10` and
`latest`. Back up persistent `/config`, then update your existing container while
preserving its token, media mounts, environment and profile data. Keep
`FOLIOSPACE_PRESERVE_GAME_CATALOG_ON_START=1` if already configured. Validate
`/api/client/info` and your normal reading/game/video workflows after upgrading.
Keep a previous image and consistent database backup; runtime rollback must not
overwrite newer reading progress with an old database.

TMDB remains optional and uses the operator's own token. See
[configuration and attribution](../tmdb-setup.md) · [中文](../tmdb-setup.zh-CN.md).
Publishing the image does not replace an existing container or release a native
App Store client. No personal library files, database snapshots or access tokens
are included in the release artifacts.

## Verification

Full Go tests and `go vet`, all 89 frontend tests, TypeScript and the production
web build passed. The ownership-migration tool passed 24 tests and the retained
MCP installer passed its two tests. Runtime fixes were accepted on isolated NAS
samples before production promotion. A subsequent 26,808-record diagnostics run
verified that all non-diagnostic database rows and source-file stat information
remained unchanged; this does not claim full page decoding or file repair.
